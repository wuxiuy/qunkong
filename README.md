# frontend · 群控台前端（GitHub Pages）

> 用途：AutoGo 群控台 Web 界面，部署到 GitHub Pages，浏览器（PC/手机）直接访问。
> 与后端解耦：只通过 `docs/api-contract.md` 的 REST 契约与数据库通信，数据库迁移无需改代码。

## 目录

```
frontend/
├── index.html              # 页面结构：安装配置 → 登录 → 主界面
├── config.js               # 默认数据库配置（仅默认值，实际以安装页保存为准）
├── assets/
│   ├── css/style.css       # 样式（含手机/PC 响应式）
│   └── js/app.js           # 逻辑：安装配置/登录/设备/任务/备份导出与恢复
└── README.md
```

## 功能

- **安装配置页**：首次打开填写数据库地址与密钥；可选"从备份恢复"（选择 JSON 备份，登录后自动恢复数据）；支持"测试连接"；
- **登录**：Supabase Auth 邮箱密码；
- **主界面**：设备列表（在线/离线、型号、IP、当前/最近任务）、常用操作（文件读写删、shell、截图、启动应用等）、任务列表（3 秒刷新）、系统管理（导出备份 JSON）；
- **手机/PC 兼容**：响应式布局，窄屏单列。

## 部署

1. 复制 `index.html`、`config.js`、`assets/` 到 GitHub 仓库（根目录或 `docs/`）；
2. 仓库 Settings → Pages → 选择分支发布；
3. 打开生成的地址，按"安装配置页"填写数据库信息即可（默认值可在 `config.js` 预填，不填也行）。

## 数据库迁移流程（前端视角）

1. 旧库群控台 → 系统管理 → 导出备份 JSON；
2. 新库执行 `backend/supabase/migrations/` 两个脚本、创建登录用户；
3. 打开群控台 → 安装配置页填新库地址/密钥 → 选择备份文件 → 保存并进入 → 登录 → 确认恢复 → 完成。
